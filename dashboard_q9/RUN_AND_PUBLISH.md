# Question 9

Open `dashboard_q9.qmd` in RStudio and click **Run Document**.
Keep its CSV (if present) and the complete `www` folder beside the QMD.

This app needs a live Shiny server. Uploading its rendered HTML to GitHub
Pages does not run the inputs.

Publish on Posit Connect Cloud with the root `PUBLISH_DASHBOARD.R` helper,
or push the QMD, CSV, `www` folder, and `manifest.json` to your public
GitHub repository and publish that QMD from Connect Cloud.
Use the final live app URL in your GitHub README.
