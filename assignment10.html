  1. Use the Adult Census Income dataset. We will predict the income (whether or not it is more than 50k or not) of an adult. Import the dataset. Partition the data into 80% training and 20% testing.
# Keep adult_census.csv in the same folder as this R Markdown file.
# The question marks in this file represent missing values.
adult <- read_csv("adult_census.csv", na = c("", "NA", "?"))
rows_before <- nrow(adult)
colSums(is.na(adult))
##            age      workclass         fnlwgt      education  education.num 
##              0           1836              0              0              0 
## marital.status     occupation   relationship           race            sex 
##              0           1843              0              0              0 
##   capital.gain   capital.loss hours.per.week native.country         income 
##              0              0              0            583              0
df <- adult %>%
  rename(target = income) %>%
  drop_na() %>%
  mutate(across(where(is.character), as.factor),
         target = factor(target, levels = c("<=50K", ">50K")))

set.seed(421)
splitIndex <- createDataPartition(df$target, p = .80, list = FALSE)
df_train <- df[splitIndex, ]
df_test <- df[-splitIndex, ]

knitr::kable(data.frame(

  Records = c(rows_before, nrow(df), nrow(df_train), nrow(df_test))

I removed 2399 records containing missing values, leaving 30162 complete records. The target is a factor with two categories: <=50K and >50K. The positive class is >50K. The split uses about 80% for training and 20% for testing, with similar income proportions in each set. All eight models use this same split.

  1. Create 3 more trees and compare the testing accuracy of these trees, which tree give the highest testing accuracy.
# A smaller cp permits additional splits in the three deeper trees.
tree_2 <- rpart(target ~ ., data = df_train, method = "class",
               control = rpart.control(maxdepth = 5, cp = .001))
tree_3 <- rpart(target ~ ., data = df_train, method = "class",
               control = rpart.control(maxdepth = 7, cp = .001))
tree_4 <- rpart(target ~ ., data = df_train, method = "class",
               control = rpart.control(maxdepth = 10, cp = .001))

tree_2_cm <- confusionMatrix(predict(tree_2, df_test, type = "class"),
                             df_test$target, positive = ">50K")
tree_3_cm <- confusionMatrix(predict(tree_3, df_test, type = "class"),
                             df_test$target, positive = ">50K")
tree_4_cm <- confusionMatrix(predict(tree_4, df_test, type = "class"),
                             df_test$target, positive = ">50K")

tree_results <- data.frame(
  Model = c("Tree 1", "Tree 2", "Tree 3", "Tree 4"),
  Maximum_depth = c(3, 5, 7, 10),
  cp = c(.01, .001, .001, .001),
  Accuracy = c(tree_cm$overall["Accuracy"], tree_2_cm$overall["Accuracy"],
               tree_3_cm$overall["Accuracy"], tree_4_cm$overall["Accuracy"]),
  row.names = NULL
)

The highest tree testing accuracy is 85.82%, achieved by Tree 4. Maximum depth limits the number of splitting levels. The complexity parameter cp controls how much a proposed split must improve the fit; a smaller value permits more splits. The table records both settings.

The forest combines predictions from many trees using a majority vote. The importance plot uses Mean Decrease Gini, which summarizes how much each predictor helps separate classes across the forest’s splits. These scores describe predictive use, not causal effects.

The best model on this testing split is Forest 1, Forest 4, with accuracy of 86.09%. For context, always predicting the majority income class on the test set would have accuracy of 75.11%.

This assignment asks us to compare models by testing accuracy. Because this same test set also helps choose the winning model, its winning score may be optimistic as an estimate of future performance. A separate final holdout set would be useful for evaluating a model selected this way.
