Findings and data notes

What the dashboard shows: Among the included passengers, the survival rate was 75.3% for females and 20.5% for males. First-class passengers had a survival rate of 65.2%, compared with 23.9% in third class. These are descriptive comparisons within this dataset.

Cleaning: The source file contains 891 passengers. Following the professor’s template, 179 records with missing age or embarkation port were removed. All plots, value boxes, and table rows use the same 712 remaining passengers. These results therefore describe this subset, rather than every passenger aboard the Titanic. Fares are displayed as recorded in the course file.

How to use it: Overview contains the summary numbers and survival charts. Distributions contains two plot tabs. Passenger Data provides searching, sorting, and pagination. Everything runs in the browser after rendering; this question uses a static Quarto dashboard.
